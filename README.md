# Beautiful Lyrics for Spotify Plus

Beautiful Lyrics turns Spotify's lyrics into a much more beautiful and animated experience. It adds animated word by word lyrics, dynamic backgrounds, lots of user customization and more! You can make your lyrics your own!

<img src="./preview/main.webp" alt="Beautiful Lyrics Preview" width="250" />

## Features

Beautiful Lyrics for Spotify Plus includes many features to make this the best listening experience you've ever had. 

* 🎵 Beautiful word by word lyrics
* 🎨 Dynamic animated background
* 🍎 Both Beautiful Lyrics and Apple Music style animations
* 🌐 Lyric translations and pronunciations
* 🎤 Spotify Sing
* ✨ Generate synced word by word lyrics for any song

## Installation

You can install beautiful lyrics with [Spotify Plus](https://github.com/LeNerd46/SpotifyPlus). Spotify Plus is an Xposed module for Android.

You can install it with LSPosed on rooted devices, or LSPatch on non rooted devices. Check the Spotify Plus repo for more information.

Once you have Spotify Plus installed, go the marketplace in the sidebar, find Beautiful Lyrics, and press install. Now you can go any song's lyrics page, and it will look beautiful!
